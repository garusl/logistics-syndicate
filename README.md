🚛 Logistics Syndicate

Logistics Syndicate — это концепт браузерного экономического симулятора нового поколения (Web2), посвященного логистике, грузоперевозкам и построению бизнес-империи.

📖 О проекте

Игра совмещает в себе механики классического "дальнобойщика" (выполнение рейсов, слежение за топливом и износом) с глубокой финансовой P2P-экосистемой.
Игроки разделены на классы: от рядовых водителей (F2P), которые зарабатывают игровую валюту (Баксы), до владельцев Транспортных Компаний, АЗС и СТО (VIP/Донатеры), которые аккумулируют эту валюту и конвертируют её в реальные средства (Бриллианты).

📂 Структура Frontend-прототипа (UI)

Текущая версия содержит верстку ключевых экранов игры, выполненную на HTML5 + Tailwind CSS + Vanilla JS.

index.html — Главная страница (Лендинг) с анимацией статистики.

dashboard.html — Личный кабинет F2P-игрока (Гараж, состояние текущей машины).

job_board.html — Биржа грузов (выбор контрактов, пейволл для слабых машин).

business_dashboard.html — Панель управления бизнесом (АЗС/СТО) для VIP-игроков.

transport_company.html — Управление Транспортной Компанией (штат, налоги, тендеры).

referrals.html — Партнерская программа (реферальная сеть).

bank.html — Центральный банк (обменник Баксов на Бриллианты, крафт Осколков, касса).

⚙️ Планируемый Технический Стек

Frontend:

Vue.js 3 / React (в перспективе PWA)

Tailwind CSS

FontAwesome 6

Backend (см. спецификацию backend_specs.md):

Node.js + NestJS

PostgreSQL 15+ (Транзакционная БД)

Redis (Таймеры, кэширование, Rate Limiting)

Prisma ORM

🚀 Как запустить локально

Так как текущий прототип написан на чистом HTML/Tailwind через CDN, установка зависимостей не требуется.

Склонируйте репозиторий.

Откройте любой из файлов .html (например, index.html) прямо в вашем браузере.

🛡️ Безопасность и экономика

Экономика игры защищена системой плавающего курса, механикой "Осколков", жесткой привязкой таймеров к Backend-серверу и анти-фрод системой на базе Browser Fingerprinting. Подробности описаны во внутренних документах проекта.
